# ToolShop

Міні-магазин інструментів (верстати, електроінструмент). Командний курсовий проєкт з Web design.

Архітектура на цьому етапі: **клієнт (HTML) → бекенд (Node.js + Express) → БД (PostgreSQL у Docker)**.

## Вимоги

- Node.js 20+
- Docker Desktop

## Запуск

```bash
npm install
npm run db:up      # запускає Postgres у Docker і створює таблицю items з тестовими даними
npm start          # API і сторінка на http://localhost:8080
```

Відкрити http://localhost:8080 і натиснути **Load items**.

Зупинити базу: `npm run db:down` (дані зберігаються у volume `db-data`).

## API

| Метод | Шлях     | Опис                                 |
|-------|----------|--------------------------------------|
| GET   | `/items` | Список товарів `[{ "id", "name" }]`  |
