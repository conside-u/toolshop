# ToolShop — roadmap

| Тиждень | Що робимо | Результат |
|---------|-----------|-----------|
| 1 | Базова архітектура клієнт → бекенд → БД | `GET /items`, сторінка «Load items», Postgres у Docker ✅ |
| 2 | Документація проєкту | `business_doc.md`, діаграма архітектури, цей roadmap ✅ |
| 3 | Моделювання домену (DDD) | Піддомени каталог / замовлення / оплата / доставка, глосарій, класи `Product`, `Order` |
| 4 | Контракт API і CRUD товарів | `openapi.yaml`, `POST/GET/PUT/DELETE /products`, `GET /health`, юніт-тести |
| 5 | Оформлення замовлень і обробка помилок | `POST /orders` з `Idempotency-Key`, ретраї й таймаути на клієнті |
| 6 | Контейнеризація | Dockerfile для API, запуск застосунку в контейнері |

Далі — CI/CD у GitHub Actions, моніторинг і розгортання в Kubernetes.
Авторизацію (ролі покупець / менеджер) додаємо після CRUD, коли з'явиться потреба розмежувати доступ.
